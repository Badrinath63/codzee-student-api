# Codzee Student API
A simple Student Management REST API built using FastAPI.
## Features
- Create a student
- List all students
- Retrieve a student by ID
- Update a student
- Delete a student
## Setup
```bash
python -m venv .venv
pip install -r requirements.txt
uvicorn main:app --reload
```
## API documentation
Open http://127.0.0.1:8000/docs after starting the server.
